# Cars Dataset - Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA)
on a cars dataset using Python.

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Objectives
- Analyze the cars dataset.
- Identify patterns and trends.
- Visualize data using graphs.
